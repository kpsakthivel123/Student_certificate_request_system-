# CertiFlow – Student Certificate Request System
## Login
Student: `student` / `student123`
Admin: `admin` / `admin123`

## Student features
- Login
- Certificate request form
- Scholarship purpose and additional notes
- Automatic Request ID
- Track request status
- View request details
- Search/filter

## Admin features
- Separate Admin Login
- View all student requests
- Approve / Reject
- View full request details
- Dashboard statistics
- Demo request and clear data

## Other
- Attractive active colours
- Responsive mobile design
- Dark mode
- LocalStorage database
- Runs offline by opening index.html

## Files
index.html, dashboard.html, style.css, script.js, README.md
